# WPAForge 1.9.25 更新日志

> 版本：1.9.25（versionCode 95）· 上一正式版：1.9.23（93）
> 本次包含 v1.9.23 之后的**全部**变更（其中 1.9.24/94 未单独发布，内容一并计入本版）。
> 运行环境：**需要 Root**（Android 8.0 及以上）。

## 新增功能

- **跑完自动恢复你的网络配置。** 以前任务结束（未命中 / 暂停 / 取消 / 异常）会把你原来那条
  网络的配置留在**最后一条候选的口令**上，你的原配置已经被删掉了 —— 手机随后就连不上自己的网。
  现在：开跑之前先登记原配置（原口令用系统密钥加密后保存），任务结束**无论什么结果**都会
  删掉候选残留、用原口令把配置重建回去，并**读回确认**真的还原了。读回没确认时会明确告诉你
  「请手动重连」；连原配置都登记不到时，这一轮**不会开跑**，并给出原因。
- **口令不再明文写进文件。** 历史记录与任务队列里保存的命中口令，改为「脱敏标签 + 系统密钥加密的
  密文」；加密通道不可用时宁可不记，也不落明文。旧版本留下的明文数据会在启动时**自动迁移**
  （迁移前先备份，不动任何记录）。
- **设置页新增「清理明文备份」。** 上面那次迁移留下的旧文件（里面是明文口令）会一直留在应用私有
  目录里；现在它存在时设置页会出现一行入口，由你决定是否删除，并如实说明：删除后就没有回滚依据，
  而且**删除不等于在闪存层面被彻底抹除**。
- **「本机已存 WiFi」页重做。** 口令**完整显示**（以前长口令会被中间省略成 `xx…yy`，根本看不清），
  每条带强度分级；**点整行即可复制口令**；顶部可按「弱口令 / 开放网络」筛选。
- **任务被中断后可续跑。** 上次没跑完的任务在下一次启动时会被标为「被中断」并保持可继续；
  续跑会**重新验证**，不沿用上一轮已经失效的实时证据。
- **当前候选有了滚动效果**：新候选从下方顶上来、旧的淡出消散，长时间盯屏不再只是"闪一下"。

## 功能改进

- **失败必须有证据。** 到期没有任何失败证据时记为「超时（无结论）」，不再冒充"密码错误"；
  「静默」也不再单独作为失败依据 —— 只有拿到可观察的证据才下失败结论。
- **成功判定更严。** 除了「目标 + 握手完成 + 有 IP」三条件，还会检查归属是否冲突；
  冲突时结论是「未确认」，**既不算命中也不算密码错**，而不是硬判成命中。
- **每条结论都能对回是哪一次尝试**：命中与失败的判词都会带上尝试标识，事后可以精确追溯。
- **速度与剩余时间改为"当前节奏"。** 以前显示的是整轮平均，会被开头几条慢的拖着
  （实测出现过显示 5.2 秒/条、实际 2.2 秒/条）；现在按最近 20 条实时计算。进度小数按量级给精度
  （大字典前几千条不再一直显示 0.0%），剩余时间超过一天改说「N 天 N 小时」。
- **「未命中」不再包含"没证据"。** 一轮里如果有无结论的候选，结束文案与列表徽章会写明
  「未命中 · 其中 N 条无结论（未能证实密码错）」，不再把证据不足说成"已证实不在字典里"。
- **顶部「目标 / 字典」不会再丢。** 后台跑一阵再回前台、或暂停后继续时，不再显示成「未选择」；
  显示会从正在运行的任务重建，且不会覆盖你新选的目标。
- **扫描更可靠**：修掉「装完给了定位权限却扫不到任何网络」的定位开关漏检。
- **观测页重做**：雷达改为每个 AP 一个点、信号越强越靠里越大，密集时自动分层不重叠；
  信号分布从"一根单调的柱状图"换成「五档统计 + 最强 10 台横向条（带网络名）」。
- **速度与保活**：每条候选耗时从约 4.9 秒压到约 2.4 秒；另修掉「后台跑着跑着不动」与
  「越跑越慢」两个老问题。

## 问题修复

- 修掉**暂停从来没停过**（暂停指令没有真正到达引擎），以及暂停收尾期间点「继续」被吞掉。
- 修掉**后台不运行**（保活从未生效）与**越跑越慢**（退避阈值定错）。
- 修掉「**跳过正确密码**」这一类漏判：某些情况下正确口令会被跳过，并补上自诊断信息。
- 修掉错误归因：上一条候选留下的日志/事件不再算到当前这条头上；归属不明时不再冒充密码错。
- 修掉**命中判词把明文口令写进任务日志文件**的问题。
- 修掉命中卡片的条号少 1（它显示的是命中前已试条数，曾误导过一次排查）。
- **连接自测不再破坏你的配置**：以前它会把你目标网络的配置换成测试口令且不还原；
  现在开始前先登记原配置，结束（成功 / 失败 / 中断 / 异常）都会自动还原并读回验证，
  登记不到就直接拒绝执行并说明原因。
- **WPS 页不再清空系统日志缓冲**：改用时段时间锚点局部读取，你抓别的日志不会再被清掉。
- 列表里长网络名 / 厂商名不再被截断成 `WP…`；顶部「Root 通道 · …」那行也不再被省略号切掉。

## 安全与隐私

- 命中口令的落盘、日志、判词全部改为不含明文；依赖系统密钥（Keystore）加密，换设备或改签名后
  解不开时会如实说明，绝不退回明文。
- 恢复机制与连接自测统一为**失败就停**（fail-closed）：无法保证能还原时宁可不开跑，
  也不会留下"错误口令留在系统里"这种静默故障。
- 公开仓库里曾经出现过的真实环境标识（口令、AP 的 MAC 设备段）已清理。

## 界面优化

- **全局统一一套设计主题**：页面 / 卡片 / 凹陷三层表面、琥珀强调色、四档按钮语义、统一圆角与字号；
  系统的对话框、状态栏、窗口底色也纳入同一套（以前是平台默认风格，和页面明显两张皮）。
- 破解页、观测页、审计页、WPS 页、设置页、字典管理、关于、局域网探测全面重排：
  设置页改为分组卡片 + 行式操作，不再是一墙大按钮；观测 / 审计 / WPS 卡片化；
  破解页细节（空状态与暂停状态区分、统计未就绪显示「—」、按钮按真实可用性置灰、底部避开手势区）。
- **换了新图标**（金色 W + 信号弧 + 雷达环）。

## 兼容性与稳定性

- **不再需要 Shizuku，也不再提供免 Root 通道**：本应用现在**不依赖任何第三方库**，只需要 Root。
  队列里历史任务存过的旧模式值会按 Root 处理，不会落到一条已经不存在的通道上。
- 发行包不再包含测试类与审计工具（包更干净）。
- 无需清除应用数据：旧数据在启动时自动迁移，历史与队列的记录条数、时间都保留。

## 已知问题

- **恢复机制的「用原口令把配置重建回去」这一条分支尚未在真机上验证**（启动补做、成功判定、
  失败留痕三条已做真机验证）；这条分支最坏结果是配置被删净 —— 属于**可见**故障，需要你手动重连一次。
- 明文备份（迁移遗留）默认保留在你决定之前；删除后不再有回滚依据，且删除不保证闪存层面被抹除。
- **历史仓库中曾公开过签名口令**：代码与文档里的该口令已移除，但**建议轮换签名口令**
  （只改口令不改密钥，应用签名指纹不变，老用户仍可覆盖安装）。
- 连接自测需要你填一个能确认密码的网络，且它仍会**临时改动**该网络配置（现在结束会自动还原）。
- WPS 功能不在上面那套配置恢复机制的覆盖范围内。
