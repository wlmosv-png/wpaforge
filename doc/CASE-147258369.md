## 3. 那「已执行 27 / 已证实 0 / 未确定 0」是什么？

那是**另一轮任务**的界面快照（用户描述的第二组数字是 22/70，
说明他跑过多轮不同字典）。该现象的真实成因已在
`fix(verdict)` 提交里修掉：

| 根因 | 位置 | 后果 |
|---|---|---|
| `VerdictTally.add` 对 ERROR 直接 `return` | 原第 83 行 | ERROR 结论**凭空消失**，不进任何一类 |
| `tested++` 在 `tryOne` 之前、`tally.add` 在之后 | 主循环 | tryOne 抛异常时 tested 涨了但 tally 没记 |

两者叠加 → 「已执行 27 / 已证实 0 / 未确定 0」。

**修复后**：ERROR 进独立的 `environmentErrors` 分类，界面显式提示
「⚠ 通道/环境出错 N 条 —— 这些条目没有被真正验证（不是密码错）」，
且新增恒等式 `executed == 已证实 + 推断 + 网络级 + 无结论` 由门禁钉住。
