更少的失败路径 · 更清楚的结论 · 更干净的界面

⚠️ **运行环境：需要 Root**（Android 8.0 及以上）。本版起**不再需要 Shizuku**，也不再提供免 Root 通道。

---

## 🔒 跑完之后，不再把你的网络留在错的口令上

引擎为了保证"这条口令到底有没有用"的归因，会先删掉目标的已保存配置、再用候选口令加回来。
于是任务结束时系统里保存的是**最后一条候选的口令**：命中时恰好正确，未命中 / 暂停 / 取消时就**是错的**，
而你原来的配置已经被删掉了 —— 手机随后连不上自己的网，只能手动重输。

这一版把这件事收干净：

- 开跑之前先**登记原配置**（原 netId + 原口令；口令用系统密钥加密保存，不落明文）；
- 任务结束**无论什么结果**（命中 / 未命中 / 暂停 / 停止 / 异常）都走同一套收尾：
  删掉候选残留 → 用原口令重建 → **读回确认**真的还原了；
- 读回没确认时**明确告诉你**，并提示手动重连；不会假装"已恢复"；
- 拿不到可靠快照（读不到配置 / 口令加密失败 / 记录写不进盘 / 盘上还有别的任务没恢复完）
  → **这一轮不开跑**，并给出原因。宁可不开跑，也不留一个还原不了的局面。

## 🧪 结论必须有证据：失败要能证明，成功要能归属

- **失败必须有证据。** 到期却没有任何失败证据时记为「超时（无结论）」，不再冒充"密码错误"；
  「静默」也不再单独作为失败依据。
- **成功判定更严。** 仍只认「目标 SSID + 握手完成 + 有 IP」三条同源于同一行输出；
  另外新增归属冲突检查 —— 拿不准时报**「未确认」**，既不算命中也不算密码错。
- **「未命中」不等于「已证实」。** 一轮里如果有没有拿到证据的候选，结束文案与列表徽章会写明
  「未命中 · 其中 N 条无结论（未能证实密码错）」，不会把证据不足说成"已证实不在字典里"。
- **每条结论都能对回是哪一次尝试**：命中与失败的判词都带上尝试标识，事后可精确追溯。

## 🔐 口令不再明文落盘

- 历史记录与任务队列里保存的命中口令，改为「**脱敏标签 + 系统密钥加密的密文**」；
  加密通道不可用时**宁可不记**，也不落明文。
- 旧版本留下的明文数据会在启动时**自动迁移**：先备份、再重写，**不删任何记录**（条数、时间都保留）。
- 明确的明文出口只有一处：你自己触发的**导出**功能与界面展示（都在本机）。
- 设置页新增「**清理明文备份**」入口（上面那次迁移留下的旧文件仍在应用私有目录里）：
  由你决定是否删除，并如实说明"删除后没有回滚依据，且删除不等于闪存层面被彻底抹除"。

## 🎛 界面：整机统一一套设计，破解页按「一眼三问」重排

- **全局设计统一**：页面 / 卡片 / 凹陷三层表面、琥珀强调色、四档按钮语义、统一圆角与字号；
  连系统对话框、状态栏、窗口底色也纳入同一套（以前是平台默认风格，和页面明显两张皮）。
- **破解页只回答三件事：跑到哪了 / 还要多久 / 刚才在试什么。**
  进度只说一遍（原来三处表达同一件事）；「正在试」独立成等宽大字区并带刚试过的两条；
  **当前候选有滚动动效**（新的从下方顶上来、旧的淡出消散）。
- **日志分级**：新增「关键 / 全部」两个视图 —— 启动自检、耗时汇总等归入明细默认不显示；
  里程碑、逐条候选结果（它是"还在干活"的心跳）与失败原因默认可见；切视图从全量重建，不丢行。
- **命中卡片**：命中不再只是日志里的一行绿字 —— 一块卡：口令等宽大字、一键复制、证据与位置。
- **设置页**改为分组卡片 + 行式操作（不再是一墙大按钮）；**观测 / 审计 / WPS** 卡片化；
  **观测页雷达**重做（每台 AP 一个点、越强越靠里、密集时自动分层不重叠），
  信号分布改成「五档统计 + 最强 10 台横向条（带网络名）」。
- **「本机已存 WiFi」**重做：口令**完整显示**（以前长口令会被中间省略成 `xx…yy`）、
  强度分级、**点整行复制口令**、可按弱口令 / 开放网络筛选。
- **换了新图标**（金色 W + 信号弧 + 雷达环）。

## 🧹 移除：Shizuku 与免 Root 通道彻底删除

从代码到清单、从依赖到界面，两条通道已彻底删除：删除 5 个相关类与随包附带的 3 个第三方 jar
（**本应用不再依赖任何第三方库**）；清单里的 Shizuku 权限、包可见性、V3 协议与 Provider 全部撤掉；
界面残留（模式切换入口、授权引导、队列模式标签）清干净；队列里老任务存过的旧模式值一律按 Root 处理。

**为什么**：Shizuku 通道每次关联都要借一次 binder；免 Root 通道每条候选都要弹一次系统确认框 ——
两者都撑不起逐条字典遍历，留着只会带来"明明选了却跑不动"的困惑。

## ⚡ 其他改进与修复

- 速度与剩余时间改用**最近 20 条的实时节奏**（以前是整轮平均，实测出现过显示 5.2 秒/条、
  实际 2.2 秒/条）；大字典前几千条的进度不再一直显示 0.0%；剩余时间超过一天改说「N 天 N 小时」。
- 顶上「目标 / 字典」在后台跑一阵回前台、或暂停后继续时**不再显示成「未选择」**。
- 每条候选耗时约 4.9 秒 → 约 2.4 秒；修掉「暂停从来没停过」「后台不运行」「越跑越慢」三个老问题。
- 修掉**跳过正确密码**这一类漏判；修掉错误归因（上一条候选的日志/事件不再算到当前这条头上）。
- 修掉命中判词把明文口令写进任务日志文件；修掉命中卡片条号少 1。
- **连接自测不再破坏你的配置**：以前它会把你目标网络的配置换成测试口令且不还原；
  现在先登记原配置，结束（成功 / 失败 / 中断 / 异常）都会自动还原并读回验证，登记不到就拒绝执行。
- **WPS 页不再清空系统日志缓冲**：改用时段时间锚点局部读取，你抓别的日志不会再被清掉。
- 列表里长网络名 / 厂商名不再被截断；启用定位后仍扫不到网络的问题已修。

## 📋 兼容性与升级

- 覆盖安装即可：签名与配置保持一致，**已保存的目标、破解进度与历史记录完整保留**。
- 旧数据（明文格式的历史 / 队列）在启动时自动迁移并保留备份，**无需清除应用数据**。
- 系统要求：Android 8.0 及以上（minSdk 26）；只需 Root。

## ⚠️ 已知问题与注意

- 恢复机制里「**用原口令把配置重建回去**」这一条分支尚未在真机上验证（启动补做、成功判定、
  失败留痕三条已做真机验证）。这条分支最坏的结果是配置被删净 —— 属于**可见**故障，需手动重连一次。
- 「清理明文备份」默认**保留**，等你决定；删除后不再有回滚依据。
- **建议轮换签名口令**：历史公开仓库里曾出现过它（源码与文档中的已移除）。
  只改口令、不改密钥则应用签名指纹不变，老用户仍可直接覆盖安装。
- 连接自测需要你填一个能确认密码的网络，且它仍会**临时改动**该网络配置（结束会自动还原）。
- WPS 功能路径不在上面那套配置恢复机制的覆盖范围内。
