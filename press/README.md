# 投稿素材包 / Press kit

用于向各平台投稿 WPAForge 时使用的图文素材。

## 内容

| 文件 | 用途 |
|---|---|
| `00-feature.png` | 1024×500 主视觉（feature graphic），适合文章头图、论坛首图 |
| `screenshots/1.png` ~ `8.png` | 真机截图（640×1355 原尺寸） |
| `screenshots-680/1.png` ~ `8.png` | 同上，放大到 680px 宽——**投稿异次元软件世界时用这一版** |
| `icon.png` | 应用图标（192×192） |
| `submit-text.txt` | 各平台通用的投稿正文（已按合规口径写好） |

## 使用注意

文案里**不要出现**这些词：破解、蹭网、万能钥匙、密码获取、免密连接、一键破解。

统一用：**无线安全自查 / 网络审计 / 关联验证 / 弱口令风险自查**。

理由不是矫情：福建通信管理局曾对同类应用作出 1 万–3 万元行政处罚，央视 315 也点名过。

## 平台差异

- **论坛（技术向）**：走"原理 + 实测"，标题带"自测""审计"
- **社区 / 内容平台**：走"我做了个工具"的开发叙事，配真机截图
- **B站**：标题和封面不要出现"破解""蹭网"
- 所有平台都带上使用边界：仅限自有或已获授权网络
