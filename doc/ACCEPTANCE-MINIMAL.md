## 测试 1：正确密码（核心）

**前置**：
- 目标 AP 是你自己的测试 AP
- 在系统设置里「取消保存」该网络
- 记录当前连接的是哪个网（验收后要恢复）

**操作**：
1. 观测页 → 选目标 AP
2. 破解页 → 字典里只放**已知正确**的密码
3. 开始

**应观察**：

| 项 | 期望 |
|---|---|
| 已验证成功 | **1**（绿色） |
| 已证实错误 | 0 |
| 未确定 | 0 |
| 环境出错 | 0 |
| 计划行通道名 | `Shizuku` |

日志应出现：
```
⚡ 密钥命中：候选#N（证据: supplicant+netId 或 supplicant · 尝试 <runId>-N）
```
判词后应带七阶段轨迹：`PRECHECK[ok] ISOLATE[ok] SUBMIT[ok] OBSERVE[ok] ATTRIBUTE[AT3] ADJUDICATE[SUCCESS] FINALIZE[persisted]`

**预期 EvidenceGrade**：`DIRECT`
**允许写 TriedSet**：❌ **不允许**（命中永不写）

**若显示「已验证成功 0 / 未确定 1」**：看判词里的 `前提不足(...)` 或 `netid-conflict` —— 那是**正确行为**（宁可报未确定，不报假成功）。

**需保存**：破解页完整截图 + 导出的日志文件
