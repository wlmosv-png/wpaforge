# WPAForge 1.9.25 · 判定链加固 + 网络配置自动恢复 + 界面统一

> 建议标题：**WPAForge 1.9.25 · 判定链加固 + 网络配置自动恢复 + 界面统一**
> 建议 tag：`v1.9.25` · target：`main`
> ⚠️ 运行环境：**需要 Root**（Android 8.0+）。本版起不再需要 Shizuku，也不提供免 Root 通道。

## 本次重点

- **跑完自动恢复你的网络配置。** 以前任务结束会把你目标网络的已保存配置留在最后一条候选的口令上
  （未命中 / 暂停 / 取消时就是错口令，而原配置已被删掉）。现在开跑前先登记原配置，
  结束无论什么结果都删掉候选残留、用原口令重建并**读回确认**；登记不到就不开跑。
  未确认还原时会明确提示手动重连 —— 不会再静默地把手机留在错口令上。
- **失败必须有证据。** 到期没证据记为「超时（无结论）」、静默不再单独判失败；
  成功判定除三条件外增加归属冲突检查，冲突时结论是「未确认」而不是硬判命中。
- **口令不再明文落盘。** 历史与队列里的命中口令改为「脱敏标签 + 系统密钥密文」；
  旧数据启动时自动迁移（先备份、不删记录）。设置页新增「清理明文备份」，由你决定是否删除旧文件。
- **界面整体统一。** 一套设计主题覆盖全部页面（含系统对话框、状态栏底色），
  破解 / 观测 / 审计 / WPS / 设置 / 字典 / 关于 / 局域网探测全面重排；**换了新图标**。

## 其他改进

- 每秒都在盯的那些数字：速度与剩余时间改用**最近 20 条的实时节奏**（以前是整轮平均，
  实测出现过显示 5.2 秒/条、实际 2.2 秒/条）；大字典前几千条的进度不再一直显示 0.0%。
- 「未命中」与「无结论」分开显示，不再把"没拿到证据"说成"已证实不在字典里"。
- 后台跑一阵再回前台、暂停后继续，顶上的「目标 / 字典」不会再显示成「未选择」。
- 观测页雷达重做（每台 AP 一个点、越强越靠里、密集自动分层），信号分布改成
  「五档统计 + 最强 10 台横向条（带网络名）」。
- 「本机已存 WiFi」页重做：口令完整显示、强度分级、**点行复制**、按弱口令/开放网络筛选。
- 当前候选滚动动效；连接自测改为"先登记、任何出口都还原"；WPS 不再清空系统日志缓冲。

## 修复

暂停从未真正停下来、后台不运行、越跑越慢、跳过正确密码的漏判、错误归因与错误失败结论、
命中判词把明文口令写进日志、命中卡片条号少 1、启用定位后仍扫不到网络、
长网络名/厂商名被截断、连接自测改完配置不还原。

## 需要你注意

1. **建议轮换签名口令**：历史公开仓库里曾出现过签名口令（源码与文档里的已移除）。
   只改口令、不改密钥的话，应用签名指纹不变，老用户仍可直接覆盖安装。
2. 旧数据会自动迁移：无需清除应用数据，迁移前会有备份文件留在应用私有目录。
3. 已知限制：恢复机制里「用原口令重建配置」这一条分支尚未做真机验证（其余分支已做）；
   连接自测仍会临时改动目标网络配置（结束会自动还原）。
